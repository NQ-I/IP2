# Exam Proctor — Interactive Code Explorer

افتح index.html بدبل كلك في Chrome أو Edge. الملف مستقل: ما يحتاج خادم، تثبيت، أو اتصال إنترنت. تقدر تنسخ index.html وحده إلى أي مجلد.

المحتوى: 29 ملفًا، فهارس دوال ومقتطفات بأسطر المصدر، بحث، علاقات، 10 رحلات تنفيذ، مفاهيم، محاكاة حسابية تعليمية، 26 ملاحظة ساكنة، وسجل تغطية واضح.

ملفات البناء المساعدة اختيارية وليست مطلوبة لعرض الصفحة. content.py هو العمل السابق المحفوظ. build_explorer.py يقرأ المصدر كنص فقط؛ لا يستورد نظام الاختبارات ولا يشغله. لا تشغل مساعد البناء إلا إذا تبي تعيد توليد HTML من المصدر المحلي.

التحقق: 14 مجموعة اختبار منطق ومحتوى عبر Node VM، وفحص صياغة JavaScript. هذا لا يعادل اختبار متصفح أو تأكيد التجاوب البصري. أداة المتصفح حجبت file://، ولم نلتف على الحجب. يُرجى فتح الملف مباشرة للمعاينة.

verification.json يسجل مقارنة SHA-256 للملفات النصية الـ199 ضمن نطاق المسح منذ استكمال هذه المحاولة. لا يوجد خط أساس قبل المحاولة السابقة أو سجل Git متاح؛ لذلك لا ندّعي إثبات عدم التغيير قبل هذه النقطة. استُبعدت البيانات الخاصة والنماذج والتسجيلات والأسرار والملفات المولدة والثنائية من نطاق القراءة/المقارنة.

العدد 212 من الجرد التاريخي؛ مسح الملفات النصية الحالي 199 بسبب اختلاف النطاق. الـ183 المتبقية قيمة تاريخية، وليست إعادة جرد بنفس المعايير. بعض الدوال لها فهرس ومقتطف فقط مع توضيح أن شرحها التفصيلي لم يُرحّل. المقاطع المساندة لا تُحسب ملفات مكتملة.
